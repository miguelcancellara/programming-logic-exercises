# 🎓 Desafio 04 - Sistema de Cadastro de Alunos

## 📖 Contexto

Uma escola precisa de um sistema simples para gerenciar seus alunos.

O sistema deverá funcionar via terminal e permitir o gerenciamento dos estudantes durante a execução do programa.

---

# 🎯 Objetivo

Desenvolver um sistema capaz de cadastrar, listar, buscar e remover alunos.

---

# 📋 Funcionalidades

- Cadastrar aluno
- Listar alunos
- Buscar aluno pelo nome
- Remover aluno
- Calcular média da turma

---

# 📌 Estrutura do Aluno

```javascript
{
    id,
    nome,
    idade,
    notas: []
}
```

---

# 📚 Conceitos praticados

- Variáveis
- Condicionais
- Laços de repetição
- Arrays
- Objetos
- Funções
- Manipulação de dados

---

# ⭐ Desafios Extras

- Não permitir alunos duplicados.
- Validar idade.
- Validar notas.
- Ordenar alunos por nome.

---

# 🚫 Restrições

Não utilizar bibliotecas externas.

---

# ✅ Critérios de conclusão

- Código organizado
- Funções pequenas
- Sem repetição de código
- README atualizado
