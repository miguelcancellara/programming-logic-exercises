# 🌐 Desafio 07 - Consumo de API

## 📖 Contexto

Criar uma aplicação que consuma uma API pública.

Será utilizada a PokéAPI.

https://pokeapi.co/

---

# 🎯 Objetivo

Pesquisar Pokémons utilizando requisições HTTP.

---

# 📋 Funcionalidades

- Buscar Pokémon
- Mostrar imagem
- Mostrar habilidades
- Mostrar tipos
- Mostrar peso
- Mostrar altura

---

# 📚 Conceitos

- Fetch API
- Async/Await
- JSON
- HTTP
- Tratamento de erros

---

# ⭐ Extras

- Histórico de pesquisas
- Favoritos
- Cache simples
- Busca parcial

---

# 🚫 Restrições

Não utilizar Axios.

Utilizar apenas Fetch.
