# 📦 Desafio 06 - Controle de Estoque

## 📖 Contexto

Uma loja precisa controlar seu estoque de produtos.

---

# 🎯 Objetivo

Criar um sistema para gerenciar produtos.

---

# 📋 Funcionalidades

- Cadastrar produto
- Editar produto
- Remover produto
- Buscar produto
- Listar produtos
- Relatórios

---

# 📌 Produto

```javascript
{
    id,
    nome,
    categoria,
    preco,
    quantidade
}
```

---

# 📊 Relatórios

- Produto mais caro
- Produto mais barato
- Valor total em estoque
- Produtos sem estoque
- Produtos por categoria

---

# 📚 Conceitos

- Arrays
- Objetos
- Algoritmos
- Manipulação de dados
- Ordenação
- Busca

---

# ⭐ Extras

- Ordenação por nome
