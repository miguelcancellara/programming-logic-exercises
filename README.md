# 📘 Programming Logic Exercises

Repositório com exercícios práticos de lógica de programação desenvolvidos em **JavaScript puro (Node.js)**, sem frameworks ou bibliotecas externas.

O objetivo deste repositório é fortalecer os fundamentos da programação por meio da resolução de problemas, documentando não apenas as soluções, mas também o raciocínio utilizado em cada exercício.

---

# 📖 Sobre este repositório

Este repositório representa minha evolução como desenvolvedor.

Os exercícios foram desenvolvidos em momentos diferentes da minha jornada e estão organizados de forma cronológica para registrar essa evolução.

> **📝 Nota**
>
> Os exercícios **01 ao 03** foram desenvolvidos originalmente em **2024**, durante meus primeiros estudos de lógica de programação em JavaScript.
>
> Eles foram adicionados posteriormente a este repositório para preservar minha evolução e documentar meu aprendizado.
>
> A partir do **exercício 04**, iniciei uma nova etapa de estudos, retomando a prática constante de programação com foco em:
>
> - resolução de problemas mais complexos;
> - código limpo;
> - organização de projetos;
> - documentação;
> - boas práticas de Git e GitHub;
> - preparação para projetos maiores envolvendo APIs, banco de dados e Programação Orientada a Objetos.

# ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/miguelcancellara/programming-logic-exercises.git
```

Entre na pasta do projeto:

```bash
cd programming-logic-exercises
```

Execute o exercício desejado:

```bash
node 01-mega-sena/mega-sena.js
```

ou

```bash
node 02-sorteio-jogadores/sorteio-jogadores.js
```

ou

```bash
node 03-soma-cfop/soma-cfop.js
```

Nos próximos exercícios, siga o mesmo padrão:

```bash
node 04-sistema-cadastro-aluno/index.js
```
