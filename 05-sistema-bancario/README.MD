# 🏦 Desafio 05 - Sistema Bancário

## 📖 Contexto

Desenvolver um sistema bancário simplificado capaz de gerenciar contas de clientes.

---

# 🎯 Objetivo

Permitir operações bancárias básicas.

---

# 📋 Funcionalidades

- Criar conta
- Depositar
- Sacar
- Transferir
- Consultar saldo
- Exibir extrato

---

# 📌 Estrutura da Conta

```javascript
{
    numero,
    cliente,
    saldo,
    extrato:[]
}
```

---

# 📚 Conceitos praticados

- Algoritmos
- Objetos
- Arrays
- Funções
- Validação
- Manipulação de dados

---

# ⭐ Desafios Extras

- Não permitir saldo negativo.
- Validar valores.
- Histórico completo de operações.

---

# 🚫 Restrições

Todo o sistema deverá funcionar em memória.

---

# ✅ Critérios

- Código limpo
- Organização
- Boa separação de funções
